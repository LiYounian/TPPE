# 灵活空位模板：1–4 个空 + 按人数挑模板 + 重写全部模板

> 状态：**已实施**（2026-10-20）。

## 一、问题

原规则要求每条模板必须同时包含「时间 / 地点 / 人物 / 事件」四个空，很多句子是硬塞进去的，读起来生硬。例如：
- `{人物}真是个显眼包，{时间}在{地点}{事件}。` → 其实一个空就够：`{人物}真是个显眼包。`
- `二舅治好了我的精神内耗：{时间}，{人物}在{地点}{事件}。` → `{时间}，{人物}治好了我的精神内耗。`

## 二、新规则（用户确认）

1. **模板含 1–4 个不同元素**，每个元素最多出现一次。
2. **按人数挑模板：空位数 ≥ 房间人数**，保证每人至少分到一个空。

| 房间人数 | 可抽模板 | 分配 |
|---|---|---|
| 1 | 1–4 空 | 一人填全部空 |
| 2 | 2–4 空 | 每人至少 1 个，多出的空轮流分 |
| 3 | 3–4 空 | 同上 |
| ≥4 | 4 空 | 选 4 人填，其余旁观、下轮优先（与原规则相同） |

被否决的另一种理解：短句子在人多时也能抽到，分不到空的人这轮旁观。缺点是人多时经常有人闲着。

3. 模板只给自己含有的元素分配空位；这些空全部填完就揭晓。投票、30 秒倒计时、超时随机、积分都不变。

## 三、模板重写原则

- 句子先要**自然好读**，元素只在句子真正需要时出现，不硬凑。
- 热梗句保留梗的原文，出处和时间不变。
- 「事件」空仍然按动宾短语设计（玩家填的是"做了什么"）。
- 为了让 4 人局有足够的选择（4 人局只能抽四元素句），**四元素句至少保留 60 条**，其余按 3 / 2 / 1 空分布。
- **模板 id 不变**（只改文字），历史句子按 id 仍能对上；不新增也不删除 id。

## 四、改动清单

| 模块 | 改动 |
|---|---|
| `templates.py` | `Template.elements`（按出现顺序）；校验改为 1–4 个不同元素；`pick(..., min_slots)` 只在空位数 ≥ min_slots 的模板里抽（没有合格的就退回空位最多的那些） |
| `room.py` | 抽模板时 `min_slots = min(人数, 4)`；只给模板内元素分配空位；完成条件为"模板内元素全部填完"；候选词只抽模板内元素 |
| `index.html` | 进度"已完成 x/n"；说明文字 |
| `admin.py` / `admin.html` | 模板列表显示空位数、可按空位数筛选；试填只填模板内元素 |
| `templates.json` | 174 条全部重写 |
| 测试 | 各人数只抽到合规模板、每人至少一个空；少于 4 空时揭晓、投票、存档、超时随机都正常；模板文件的空位分布（四元素句 ≥60） |
